# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build a classic Hangman game in Python using strings, loops, conditionals, and user input to create an interactive word-guessing experience.

## 📝 Tasks

### 🛠️ Set Up the Game

#### Description
Create the core game logic for a Hangman game by selecting a hidden word and tracking the player's guesses.

#### Requirements
Completed program should:

- Randomly choose a word from a predefined list of words
- Display the word as blank spaces or underscores for each letter
- Accept single-letter guesses from the player
- Show the current progress after each guess

### 🛠️ Track Progress and End the Game

#### Description
Add the gameplay rules that determine whether the player continues guessing, wins the round, or loses after running out of attempts.

#### Requirements
Completed program should:

- Track incorrect guesses and remaining attempts
- Reveal correctly guessed letters in the hidden word
- End the game when the word is fully guessed or the player runs out of attempts
- Display a clear win or lose message at the end of the round
